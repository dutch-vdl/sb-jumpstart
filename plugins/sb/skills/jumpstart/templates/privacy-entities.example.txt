# "Sauber", ohne einen einzigen echten Namen geprueft zu haben — falsche
# Sicherheit, die von allein nie auffaellt. Alle Zeilen unten sind also zu
# ERSETZEN, nicht zu aktivieren.
#
# Format, eine Angabe pro Zeile:
#   Beispielkunde GmbH   wortweise Suche, Gross-/Kleinschreibung egal
#   =ABC                 exakte Schreibweise mit Wortgrenzen (verhindert
#                        Treffer auf Kleinschreibung und auf Wortbestandteile)
#   re:PRJ-\d{4}         regulaerer Ausdruck
#   ?Firma GmbH          Klaerungsfall statt Sperre — siehe unten
#   # Zeile mit Raute    Kommentar
#
# Die Praefixe lassen sich kombinieren: ?=ABC und ?re:… sind gueltig.

# DER EIGENE ARBEITGEBER GEHOERT ALS KLAERUNGSFALL HINEIN

# Praefix '?' loest deshalb EINMAL PRO DATEI eine Rueckfrage aus, statt zu

# sinnvollerweise im Frontmatter:
#
#   jumpstart-checked: Frage 4 geprueft, nur Methodenkern uebernommen
#
# Danach ist die Datei dauerhaft still.
