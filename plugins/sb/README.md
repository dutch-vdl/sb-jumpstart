# sb — Plugin

Sechs Verfahren für den Aufbau und die Pflege einer persönlichen Wissensbasis:

| Skill | Zweck |
|-------|-------|
| `jumpstart` | Wissensbasis von Grund auf einrichten |
| `extract` | Originaldokument zu wiederverwendbarem Wissen destillieren |
| `insight` | Externe Studie, Report oder Marktdaten aufnehmen |
| `weekly-review` | Wöchentlicher Pflegedurchlauf |
| `hub-commit` | Stand sichern, Version setzen, prüfen |
| `jumpstart-upgrade` | Bestehende Basis auf eine neuere Setup-Fassung heben |

Ausführliche Erklärung für Anwender: `docs/skills.md` im Wurzelverzeichnis des Repos.

Die Skills sind Markdown-Dateien. Sie funktionieren auch **ohne** Installation — Claude kann
sie nachschlagen und ausführen. Die Installation bringt den Kurzaufruf (`/sb:extract`) und
das automatische Auslösen.
